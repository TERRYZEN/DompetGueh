- Flutter 3.35.7, Dart 3.9.2, JDK 17, Android SDK 35.
- Analisis Dart: No issues found.
- 11 pengujian Flutter lolos: UI responsive 360/390/430/800 piksel,

- Tanda tangan APK v2 terverifikasi; sertifikat sama dengan APK offline lama.
- ZIP alignment native 16 KiB terverifikasi.
- Tidak ada izin INTERNET dalam APK release.

- Semua layar menggunakan widget Flutter; tidak ada aset HTML/CSS/JavaScript.
- Hasil render layar terang, gelap, histori, dan PIN ditinjau.
- Belum diuji melalui emulator Android atau langsung pada HP fisik.

render berbeda, sehingga kesamaan piksel 100% tidak dijanjikan.
